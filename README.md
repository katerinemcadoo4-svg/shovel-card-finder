# 铲牌练习

面向 iOS 17 及以上 Safari 的金铲铲之战看图答题 PWA。首页每套随机生成 20 道角色名字选择题，选择后立即显示对错，每题 5 分，满分 100 分。完成后显示总分、正确率和错题回顾，可重新开始一套题。角色图鉴支持 1～5 费分类、费用筛选、名字与羁绊搜索。各页面保持上下滑动，隐藏滚动条。

线上地址：https://katerinemcadoo4-svg.github.io/shovel-card-finder/

## 角色图片与资料

- 官方资料于 2026-10-04 核对，2026-10-05 再次确认当前版本为 S19「自然之力」18.18.3。`data/season.json` 收录 65 名角色及费用、羁绊、技能、基础属性；64 名有阵容建议，49 名有装备建议。每个来源的网址与核对日期保存在资料文件和角色详情中。
- 官方角色图片的公开再分发许可未经确认，因此公开站点不分发角色图片。请把个人素材 ZIP 传到 iPhone 的“文件”，在应用“资料”页导入。ZIP 只保存在该设备的 IndexedDB，不上传到服务器。没有素材包时仍可浏览图鉴文字资料。
- 至少两名有图片、名字不同的角色才能出题。优先使用头像素材；有至少 20 名可用角色时，一套题内不重复角色。少于 20 名时会轮换素材并在开始前提示。每题最多四个不同名字的选项。
- 导入或移除素材包后会重置当前题目。切换页面会保留正在进行的答题；刷新页面会重新开始。图片加载失败时不接受答案，需重新导入素材包。

## 本地运行

需要 Node.js 20 或更新版本，无需安装 npm 依赖。

```powershell
npm test
npm run build
npm run preview
```

预览地址为 `http://127.0.0.1:8765/shovel-card-finder/`，模拟 GitHub Pages 仓库子路径。localhost 不注册 Service Worker；离线与主屏幕安装应在正式 HTTPS 地址和 iPhone Safari 上验证。个人素材 ZIP 的生成方法见 `scripts/PERSONAL_PACK.md`，生成物只能留在 `local-packs/` 或项目外，不能提交到公开仓库。

## 部署与安装

1. 推送源文件到公开仓库 `main`。提交前核对文件清单；`.gitignore` 排除 `local-packs/` 和 `dist/`，构建脚本使用公开文件白名单。
2. 仓库 Settings → Pages → Source 设为 GitHub Actions。Pages 工作流运行测试、构建和部署。
3. 用 iPhone Safari 打开线上地址，点击分享 → 添加到主屏幕，再从图标启动。

首次访问和更新需要联网。应用代码、文字资料与图标由 Service Worker 缓存；个人素材保存在 IndexedDB。新版本准备好后点击“立即更新”。iOS 可能回收长期未使用站点的本地存储，请保留个人 ZIP 以便重新导入。主屏幕启动、断网重启和更新仍需在实体 iPhone 验证。

历史识别模块、OpenCV/OCR 文件及评测脚本保留在源代码中，当前答题站点不加载或打包这些文件。回滚时恢复上一版 `main` 提交并重新部署；构建内容哈希会生成新的 Service Worker 缓存。
